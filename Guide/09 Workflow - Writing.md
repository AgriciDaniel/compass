# Workflow 7: Writing

Video: 16:42 to 18:36. "Just keep writing."

## Why in the vault
Source material and draft share the vault (17:07). Drafting a newsletter and need the quote from a 2023 book note? Link it, embed it (`![[Book#^quote-id]]`), keep writing. No search, copy, paste, reformat.

## Structure (17:42)
| Type | Folder | Board | Template | Export target (Mike's) |
| --- | --- | --- | --- | --- |
| Newsletter | `06 Writing/Newsletters` | `Newsletter Board` | `Templates/Newsletter.md` | Kit |
| YouTube script | `06 Writing/YouTube Scripts` | `YouTube Board` | `Templates/YouTube Script.md` | editor's Notion |
| Article | `06 Writing/Articles` | `Article Board` | `Templates/Article.md` | Ghost (Practical PKM) |
| Course content | `06 Writing/Course Content` | `Course Board` | `Templates/Course Lesson.md` | course platform |
| Book notes | `07 Library/Book Notes` | none | `Templates/Book Note.md` | source material |

Board lanes: Backlog → Outlining → Drafting → Editing → Ready to publish → Published. QuickAdd commands drop ideas into each backlog (17:51). Drag left to right. Creating a note from a card uses the folder's template (board settings), so the metadata is right from the start.

These are **task notes**: the task is the note and the writing happens in it (18:08), unlike the inline tasks in workflow 6.

## Practices
- Give every quote in a book note a block id (`^quote-1`) the moment you capture it.
- Keep the `sources` property honest; the book note's "Linked writing" query shows where each idea ended up.
- Export at the end only. Blank page to final draft stays in Obsidian (18:30).
