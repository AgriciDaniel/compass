# 简体中文术语表

[中文 README](../../README.zh-CN.md) · [从这里开始](00%20Start%20Here.zh-CN.md) · [配置与本地化](01%20Configuration%20and%20Localization.zh-CN.md)

翻译显示文字时使用下表。文件名、目录、属性键、命令 ID、标签和被引用的标题保持原样。产品名称 Compass、Life OS、Obsidian 和插件名称不翻译。

| English | 简体中文 | 说明 |
| --- | --- | --- |
| Vault | 笔记库 | Obsidian 打开的整个目录 |
| Dashboard | 仪表盘 | 由已有笔记和属性生成的汇总视图 |
| Home | 首页 | Life OS 的总览入口 |
| Today | 今天 | 当天记录与问题 |
| Plan | 规划 | 多个时间尺度的规划入口 |
| Focus | 专注 | 按时间状态整理待办事项 |
| Review | 回顾 | 记录趋势与周期回顾 |
| Projects | 项目 | 具体成果与相关任务 |
| People | 人物 | 关系笔记和待讨论事项 |
| Create | 创作 | 写作与内容流程 |
| Library | 资料库 | 阅读、书籍及来源笔记 |
| Brain | 大脑图谱 | Life OS 中的笔记关联图 |
| Note labels (graph) | 笔记名称 | 图谱中显示的笔记名称，区别于 `#` 标签 |
| Tag | 标签 | 笔记或任务中的 `#` 标签 |
| Capture | 记录 | 使用既有路由添加记录或创建笔记 |
| Journal | 日记 | 正文仍使用 `## Journal` 标题 |
| Daily Questions | 每日问题 | 以 1 到 10 分评价自己的努力 |
| Effort | 努力程度 | 评价投入，避免用结果好坏代替 |
| Habit | 习惯 | 日记中的 `habit_*` 复选框属性 |
| Personal Retreat | 个人复盘 | 按季度进行的集中反思与规划 |
| Wheel of Life | 生活之轮 | 个人复盘中的各生活领域评分 |
| Multi-scale Planning | 多尺度规划 | 连接每日、每周和季度规划 |
| Life Theme | 生活主题 | 长期方向的简短表述 |
| Core Values | 核心价值观 | 规划的价值基础 |
| Ideal Week | 理想的一周 | 一周时间安排的参考结构 |
| Commitment | 待办事项 | 需要投入精力的事项；在任务列表中指未完成任务 |
| Kanban Board | 看板 | 由列和卡片组织的流程 |
| Newsletter | 电子简报 | 面向订阅者的写作与发布类型 |
| Frontmatter | 文首属性 | Markdown 顶部的 YAML 数据 |
| Sample / Example | 示例 | 展示用数据，不是真实个人记录 |
| Development Candidate | 开发候选版 | 用于开发验证，尚未通过全部发布验收的产物 |
| Native Acceptance | 原生验收 | 在实际 Obsidian 环境内验证工作流 |
| Prompt | 提示词 | 供 AI 代理执行的工作流指令 |
| Assistant | 助手 | 可选的 AI 工作流入口 |

英文原文可能使用同一词描述不同的操作，翻译时优先以实际行为为准。例如 Capture 在创建新笔记时可以显示“新建”，Review 在图表模块中表示“回顾”，Personal Retreat 表示一次专门的“个人复盘”。
